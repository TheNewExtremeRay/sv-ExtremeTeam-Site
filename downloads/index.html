Distribution notes

SafeView ships as a portable zip. These notes cover what that means — without inventing release details that don’t exist yet.

Is there an installer?

No. SafeView is distributed as a portable .zip archive: extract it to a folder and run the application from there. There is no setup wizard and no installation step — when a release is published, its entry above describes exactly which files the archive contains.

Where do the download links point?

Each release entry in the SAFEVIEW_RELEASES constant carries its own verified URL. Release 1.0.0 points directly to the SafeView-v1.0.0.zip asset in the TheNewExtremeRay/FractalSafeView repository’s GitHub Releases — every file listed here is real, linked and live.

Does SafeView sandbox my system?

No — and it says so directly. SafeView re-encodes untrusted media before playback as one additional layer of defense; it does not sandbox or isolate the playback environment and it does not claim to make malicious files risk-free. The complete security position, including the limitations statement, is on the main site.
